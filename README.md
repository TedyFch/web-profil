# Web Profil - Tedy Fachrudin

Website profil pribadi Tedy Fachrudin — Mahasiswa Teknik Informatika Universitas Muhammadiyah Jakarta & Peserta Bangkit Academy 2024 (Cloud Computing Learning Path).

## 🚀 Fitur
- **Header & Profil**: Foto profil, nama, serta ringkasan peran.
- **My Story & Personal Information**: Cerita singkat latar belakang dan kontak pribadi.
- **My Vacation Gallery**: Galeri dokumentasi perjalanan dan aktivitas.
- **Social Media Links**: Tautan terhubung ke GitHub, LinkedIn, dan Instagram.

## 🛠️ Teknologi yang Digunakan
- **HTML5** — Struktur halaman web semantik.
- **CSS3** — Desain tata letak responsif dan styling modern.
